# DNS Query Utility – React Frontend

A modern, lightweight React UI that helps you generate a C program to perform DNS queries via a specified network interface. Everything runs client-side.

## Run locally

- npm install
- npm start
- Open http://localhost:3000

## Features

- Ocean Professional theme (primary #2563EB, secondary #F59E0B)
- Form inputs: interface, DNS server, domain, record type, timeout, retries, and raw socket toggle
- Live C code preview with copy and download
- Makefile snippet and compile/run instructions
- Inline validation and localStorage persistence
- No backend calls
